# Salifort Motors - Employee Turnover Prediction

## Project Overview
This repository contains the capstone project for the **Google Advanced Data Analytics Certificate**. 

The goal of this project is to analyze survey data from **Salifort Motors**—a fictional alternative energy vehicle manufacturer—and build a predictive model to determine whether an employee is likely to leave the company, providing actionable insights to improve employee retention.

## Business Problem
The senior leadership team at Salifort Motors aims to increase employee retention. Using survey metrics (including department, number of projects, average monthly hours, and performance data), we develop machine learning models to identify employees at risk of leaving and uncover key drivers of turnover.

## Objectives
- **Exploratory Data Analysis (EDA)**: Understand turnover patterns and key correlations.
- **Data Preprocessing**: Handle missing values, encode categorical variables, and scale features.
- **Predictive Modeling**: Train and evaluate predictive models (Regression or Tree-based models such as Random Forest and XGBoost).
- **Business Insights**: Provide actionable recommendations to improve employee satisfaction and retention.
